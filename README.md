# Учёт инструмента — версия 2.2

Статический сайт для GitHub Pages.

## Что изменено

- Оформление сохранено.
- В правом верхнем углу добавлена кнопка-шестерёнка.
- Через шестерёнку можно добавлять, переименовывать и удалять инструменты без изменения кода.
- При первом открытии неизвестной NFC-метки сайт сам предлагает ввести название инструмента.
- В NFC-метке остаётся только постоянный ID, например:
  `https://anatolii-gif.github.io/tool-accounting/?tool=000001`
- На основном экране отображается название инструмента, а ID остаётся вспомогательным номером.
- Выдача, возврат, история и CSV работают как раньше.

## Важно

Справочник инструментов и история пока хранятся в браузере телефона через localStorage.
На другом телефоне данные автоматически не появятся. Для общей базы на нескольких устройствах понадобится облачное хранилище.
