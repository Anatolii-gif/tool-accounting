# Учёт инструмента — NFC-версия

Метка должна содержать URL такого вида:

https://anatolii-gif.github.io/tool-accounting/?tool=000001

Логика:
- если инструмент свободен, показывается только форма выдачи;
- если инструмент уже выдан, показывается только форма возврата;
- после выдачи/возврата экран переключается автоматически;
- кнопки повторного Web NFC-сканирования удалены, поэтому два обработчика больше не конфликтуют.

## Обновление GitHub Pages

Замените в репозитории файлы:
- index.html
- app.js
- style.css
- README.md

В HTML добавлены версии `?v=3` для app.js и style.css, чтобы мобильный браузер не использовал старый кэш.

Важно: история хранится в localStorage конкретного браузера/телефона. На другом телефоне она не появится без подключения общей базы данных.
