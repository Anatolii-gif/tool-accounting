# Учёт инструмента — версия 2.0

Статический сайт для GitHub Pages. NFC-метка должна содержать URL вида:

`https://anatolii-gif.github.io/tool-accounting/?tool=000001`

## Логика

- инструмент свободен → показывается форма выдачи;
- инструмент уже выдан → показывается форма возврата;
- данные хранятся локально в браузере телефона через `localStorage`;
- история экспортируется в CSV.

## Установка на GitHub Pages

1. Загрузить в корень репозитория файлы `index.html`, `app.js`, `style.css`, `README.md`.
2. Открыть Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/(root)`.
5. Сохранить и подождать публикацию.

## Важно

Эта версия хранит данные только на том телефоне и в том браузере, где выполняются выдачи и возвраты. Для синхронизации между несколькими телефонами позже понадобится облачная база данных.
