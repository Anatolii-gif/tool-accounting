# Учёт инструмента

Откройте `index.html`.

Функции:
- выдача инструмента;
- имя сотрудника;
- дата и время;
- фото;
- возврат без указания, кто вернул;
- история;
- экспорт CSV;
- попытка чтения NFC через Web NFC;
- ручной ввод как запасной вариант.

Сейчас данные хранятся только в браузере этого телефона.
